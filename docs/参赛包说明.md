# 中国国际大学生创新大赛（2026）参赛作品包

## 一、项目决策总览

经过对大赛规则、评审标准、政策环境与团队技术储备的调研，本项目确定为：

| 项目 | 内容 |
|------|------|
| 项目名称 | 心聆——青少年心理健康多模态智能筛查与早期预警平台 |
| 参赛赛道/组别 | 高教主赛道 / 本科生创意组（研究生组请修改封面） |
| 参赛类别 | 人工智能+ |
| 所属领域 | 信息技术服务业 |
| 项目进展 | 创意计划阶段 |
| 产品定位 | 面向学校心理健康普查的“客观量化筛查＋分级预警＋干预追踪”平台 |
| 核心技术 | 干电极脑电采集、差分熵/功率谱特征、跨被试 Transformer、联邦学习、可解释决策 |
| 商业模式 | 软件订阅＋硬件租赁＋增值服务（B2B2C） |

### 为什么选这个方向

1. **政策强驱动**：教育部等十七部门要求学校每学年至少一次全员心理测评，并明确鼓励人工智能赋能心理健康工作，需求是刚性的。
2. **痛点真实且评审友好**：传统量表存在社会赞许效应、漏报率高、师资不足三大痛点；高教主赛道创意组 30 分看“项目创新”，脑电＋多模态＋隐私保护的组合能讲出清晰的差异化创新故事。
3. **与团队研究积累匹配**：脑电情绪识别、Transformer、多模态融合正是本项目可依托的技术储备，容易形成“科研—竞赛—创业”闭环。
4. **社会价值突出**：契合健康中国、立德树人导向，同时具备可测算的市场空间（学校普查 SaaS）。

## 三、报名表单填写要点

详细可复制内容见 [报名表单填写内容.txt](报名表单填写内容.txt)。最需要注意的三点：

1. **项目名称提交后不可修改**，提交前请与团队成员确认。
2. **项目概述限 100—1000 字且不能含英文字母或符号**，模板文本已全部使用中文与中文标点；复制前请再自查。
3. **“学校科技成果转化”与“申报人为成果第一完成人”两项需联动填写**：创意组下学校成果转化项目不能参赛（除非申报人排名第一），模板默认建议“否”，如确为个人第一完成人的学校成果再改“是”。

## 四、项目计划书说明

计划书严格对标知识库排版规范：

- A4 页面，上下左右页边距均为 2.5cm；
- 题目三号黑体居中，一级标题四号黑体居中，二级/三级标题小四黑体左对齐，正文小四宋体，西文 Times New Roman，1.5 倍行距；
- 页脚仅页码，无页眉；三线表、图题在下表题在上、公式连续编号并全部被正文引用；
- 参考文献按 GB/T 7714 顺序编码制；
- 因大赛计划书要求“统一目录、页码”，额外加入了目录（数模训练中的“无目录”规则不适用于商业计划书场景）。

全文共 10 章：项目概述、行业分析与政策背景、市场调研与竞品分析、产品与技术方案、创新点与技术壁垒、商业模式、财务分析与融资计划、团队介绍、风险管理、社会价值与发展规划，另附参考文献与附录（伪代码、推导、术语表、支撑材料清单）。

### 重新编译

```powershell
cd 项目计划书
xelatex -interaction=nonstopmode -output-directory=build project_plan.tex
```

需连续编译 3 次（目录与交叉引用），最终 PDF 位于 `build/project_plan.pdf`，可复制为 `心聆项目计划书.pdf`。

## 六、数据诚信与合规提醒

- 计划书中所有市场数据均标注了来源；未经验证的数据一律以“目标值”“假设”“测算”措辞呈现，请勿在路演中将其表述为已实现结果。
- 脑电属于敏感神经数据，务必完成校级伦理审查、知情同意流程与个人信息保护影响评估后再开展真实采集。
- 产品坚持“客观筛查、专业复核、非医疗诊断”定位，避免与医疗器械注册监管冲突。
