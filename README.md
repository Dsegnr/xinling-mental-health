## 是什么

当前学校心理普查主要依赖问卷量表，学生容易受主观意愿影响而隐瞒真实状态，漏报率偏高。心聆以**脑电信号为主、心率与量表为辅**，用客观生理指标做一次"无感筛查"：

- 干电极脑电头环 + 标准化情绪诱发任务，五分钟完成一次筛查
- 差分熵与功率谱密度特征 + 跨被试情绪识别模型
- 输出低 / 中 / 高三级风险，由学校心理教师复核
- 自动生成分级干预建议，为高危学生开通预警与转介通道

边界很明确：**客观筛查、专业复核、非医疗诊断**。数据加密存储、本地推理，未经家长与本人知情同意不对外提供。
